테일러 급수 실전 활용 (Applications)

테일러 급수를 활용하면 복잡한 극한을 직관적으로 풀 수 있고, 초등함수로 적분되지 않는 함수(Nonelementary Integral)의 근사값을 정밀하게 계산할 수 있습니다.
Ex 1. 극한 (Limits)
예제 1. $\lim_{x \to 0} \frac{x^2 e^x}{\cos x - 1}$ 의 값을 테일러 급수로 구하시오.
[급수 전개] $x=0$ 근처에서 다음 급수를 대입한다.
  • $e^x = 1 + x + \frac{x^2}{2} + \dots$
  • $\cos x = 1 - \frac{x^2}{2} + \frac{x^4}{24} - \dots$
[대입 및 계산]
$$\lim_{x \to 0} \frac{x^2(1 + x + \dots)}{(1 - \frac{x^2}{2} + \dots) - 1} = \lim_{x \to 0} \frac{x^2 + x^3 + \dots}{-\frac{x^2}{2} + \dots}$$
최저차항인 $x^2$으로 나누면 극한값은 **-2**이다.
Ex 2. 적분 (Integration)
예제 2. $\int_0^1 e^{-x^2} dx$ 를 소수점 셋째 자리까지 근사하시오.
[급수 전개] $e^t = \sum \frac{t^n}{n!}$ 이므로 $e^{-x^2} = 1 - x^2 + \frac{x^4}{2} - \frac{x^6}{6} + \dots$ [항별 적분]
$$\int_0^1 (1 - x^2 + \frac{x^4}{2} - \dots) dx = [x - \frac{x^3}{3} + \frac{x^5}{10} - \frac{x^7}{42} + \dots]_0^1$$
$1 - 0.3333 + 0.1 - 0.0238 \approx 0.743$ (가우스 적분의 유한 구간 근사).
Ex 3. 급수의 합 (Summation)
예제 3. $\sum_{n=1}^{\infty} \frac{n}{2^n}$ 의 값을 구하시오.
[생성 함수] 기하급수 $\frac{1}{1-x} = \sum x^n$ 을 이용한다 ($|x|<1$). [미분] 양변을 미분하면 $\frac{1}{(1-x)^2} = \sum_{n=1}^{\infty} n x^{n-1}$. [대입] 양변에 $x$를 곱하면 $\frac{x}{(1-x)^2} = \sum_{n=1}^{\infty} n x^n$. $x = 1/2$를 대입하면 $\frac{1/2}{(1-1/2)^2} = \frac{1/2}{1/4} = 2$.
Ex 4. 오차 분석 (Error Bound)
예제 4. $\sqrt{1.1}$ 을 2차 테일러 다항식으로 근사하고 오차 범위를 구하시오.
[이항 급수] $f(x) = (1+x)^{1/2}$ 에서 $a=0, x=0.1$.
$$P_2(0.1) = 1 + \frac{1}{2}(0.1) - \frac{1}{8}(0.1)^2 = 1.04875$$
[나머지항] $|R_2(0.1)| \le \frac{M}{3!}(0.1)^3$ ($M$은 $f'''$의 최댓값). 이를 통해 실제값과 근사값 사이의 수학적 신뢰도를 확보한다.
Ex 5. 복소 해석 입문 (Euler's Formula)
예제 5. 테일러 급수를 이용해 $e^{ix} = \cos x + i \sin x$ 임을 보이시오.
[지수 급수 대입] $e^{ix} = 1 + (ix) + \frac{(ix)^2}{2!} + \frac{(ix)^3}{3!} + \frac{(ix)^4}{4!} + \dots$ [정리] $i^2 = -1, i^3 = -i, i^4 = 1$임을 이용해 실수부와 허수부로 묶는다.
$$e^{ix} = \left( 1 - \frac{x^2}{2!} + \frac{x^4}{4!} \dots \right) + i \left( x - \frac{x^3}{3!} + \frac{x^5}{5!} \dots \right)$$
괄호 안은 각각 $\cos x$와 $\sin x$의 매클로린 급수와 정확히 일치한다.
테일러 급수는 현대 공학에서 비선형 시스템을 선형화(Linearization)하여 해석하는 가장 근본적인 수단입니다.
